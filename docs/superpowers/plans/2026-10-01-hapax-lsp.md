# hapax-lsp Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task.
> Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A language server giving Hapax instrument definitions diagnostics, semantic-token highlighting, completion and a fix-all action in any LSP editor.

**Architecture:** `features.py` holds stateless functions from document text to `lsprotocol` types, built on hapax-tui's `parse`, `validate` and `fix`.
`server.py` is a thin pygls 2 wrapper holding settings and routing LSP events to those functions.
Neovim support ships as a runtime directory (`editors/nvim`) with filetype detection and an `lsp/hapax.lua` config.

**Tech Stack:** Python 3.13, uv, hatchling, pygls 2.1, lsprotocol 2025, hapax-tui (git), pytest, Neovim 0.11+.

**Spec:** `docs/superpowers/specs/2026-10-01-hapax-lsp-design.md`

## Global Constraints

- Python `>=3.13` (hapax-tui's floor).
- Dependencies: `pygls>=2.1` and `hapax-tui @ git+https://github.com/claytron/hapax-tui`; no others at runtime.
- hapax-tui is the single source of truth: no ranges, enumerations or rules are re-implemented here; import them from `hapax.parse`, `hapax.rules`, `hapax.fix`.
- Diagnostic `source` is `hapax`; `code` is the hapax-tui finding code.
- Settings shape: `{ "fw": "3.21", "warn": true }`, top level in `initializationOptions`, nested under `hapax` in `didChangeConfiguration`.
- Semantic token legend: `keyword`, `enumMember`, `number`, `string`, `namespace`, `comment`; no modifiers.
- Completion trigger characters: `[`, `/`, space.
  The spec also listed `:`; it is dropped because no completion is offered after a colon.
- The server speaks stdio; command `hapax-lsp`; also runnable as `python -m hapax_lsp`.
- No trailing whitespace; every new file ends with a newline.
- Markdown: one sentence per line; run `rumdl check --fix` on new Markdown files.

## Review Focus

- CRLF documents: a client that sends `\r\n` must get the same highlighting as `\n` (test in Task 2).
- Completion in a section left open at end of file must still work (test in Task 3).
- Cursor positions past the last line, as clients send while a buffer is changing, must not raise (test in Task 3).
- A bad `fw` setting must be logged and leave the previous firmware in place, never crash the server (test in Task 5).
- A `.txt` file that is not a Hapax definition must stay filetype `text` in Neovim (check in Task 6).

```python
"""LSP features as pure functions of document text; server.py only wires them up."""

import re

from hapax.fix import fix
from hapax.parse import SECTIONS, Directive, Severity, parse
from hapax.rules import (
    DIRECTIVES, INPORTS, LATEST, MAXRATES, OUTPORTS, TYPES, TYPES_3_20, check_file_name, validate,
)
from lsprotocol import types as t


def diagnostics(text: str, fw=LATEST, file_name: str | None = None, warn: bool = True) -> list[t.Diagnostic]:
    findings = validate(parse(text), fw) + (check_file_name(file_name) if file_name else [])
    lines = text.split("\n")
    return [_diagnostic(f, lines) for f in findings if warn or f.severity is Severity.ERROR]


def _diagnostic(f, lines: list[str]) -> t.Diagnostic:
    line = max(f.line - 1, 0)  # line 0 is the whole file
    start, end = (f.span.start, f.span.end) if f.span else (0, len(lines[line]) if line < len(lines) else 0)
    return t.Diagnostic(
        range=t.Range(t.Position(line, start), t.Position(line, end)),
        message=f.message,
        severity=t.DiagnosticSeverity.Error if f.severity is Severity.ERROR else t.DiagnosticSeverity.Warning,
        code=f.code,
        source="hapax",
    )
```

```python
def decode(data):
    """Semantic token data back to absolute (line, col, length, type) tuples."""
    out, line, col = [], 0, 0
    for i in range(0, len(data), 5):
        dl, dc, length, kind, _ = data[i : i + 5]
        line, col = line + dl, (col + dc if dl == 0 else dc)
        out.append((line, col, length, TOKEN_TYPES[kind]))
    return out
```

```python
TOKEN_TYPES = ["keyword", "enumMember", "number", "string", "namespace", "comment"]
_HEADER = re.compile(r"[ \t]*(\[/?[^\]]*\])")
_NUMBER = re.compile(r"-?[0-9]+(\.[0-9]+)?V?", re.I)
_DEFAULT = "DEFAULT="
```

```python
def semantic_tokens(text: str) -> list[int]:
    doc = parse(text)
    tokens = []  # (line, start, end, type), 0-based
    for e in [*doc.directives, *(e for s in doc.sections for e in s.entries)]:
        for field, span in e.spans.items():
            if kind := _kind(e, field, e.raw[span.start : span.end]):
                tokens.append((e.line - 1, span.start, span.end, kind))
            if field == "default" and e.raw[: span.start].upper().endswith(_DEFAULT):
                tokens.append((e.line - 1, span.start - len(_DEFAULT), span.start, "keyword"))
    for n, raw in enumerate(doc.lines):
        body, hash_, _ = raw.partition("#")
        if m := _HEADER.fullmatch(body.rstrip(" \t\r")):
            tokens.append((n, m.start(1), m.end(1), "namespace"))
        if hash_:
            tokens.append((n, len(body), len(raw.rstrip("\r")), "comment"))
    return _encode(sorted(tokens))


def _kind(entry, field: str, raw: str) -> str | None:
    if field in ("name", "text") or (isinstance(entry, Directive) and entry.key == "TRACKNAME" and field == "value"):
        return "string"
    if field in ("key", "type") or raw.upper() == "NULL":
        return "keyword"
    if field == "junk":
        return None
    return "number" if _NUMBER.fullmatch(raw) else "enumMember"


def _encode(tokens) -> list[int]:
    data, prev_line, prev_start = [], 0, 0
    for line, start, end, kind in tokens:
        delta = start - prev_start if line == prev_line else start
        data += [line - prev_line, delta, end - start, TOKEN_TYPES.index(kind), 0]
        prev_line, prev_start = line, start
    return data
```

```python
def completion(text: str, line: int, character: int, fw=LATEST) -> list[t.CompletionItem]:
    lines = text.split("\n")
    before = lines[line][:character] if line < len(lines) else ""
    if "#" in before:
        return []
    stripped = before.lstrip(" \t")
    words = stripped.split()
    trailing = before[-1:] in (" ", "\t")
    # index of the word under the cursor; a trailing space starts the next one
    at = len(words) if trailing or not words else len(words) - 1
    section = _section_at(parse(text), line + 1)

    if stripped.startswith("[/"):
        return [_item(f"{section}]")] if section else []
    if stripped.startswith("["):
        return [_item(f"{s}]") for s in sorted(SECTIONS)]
    if section is None:
        if at == 0:
            return [_item(d) for d in sorted(DIRECTIVES)] + [_item(f"[{s}]") for s in sorted(SECTIONS)]
        if at == 1:
            return _values(words[0].upper(), fw)
    elif section in ("ASSIGN", "AUTOMATION"):
        target = 1 if section == "ASSIGN" else 0
        if at == target:
            return [_item(x) for x in _TARGETS + (["NULL"] if section == "ASSIGN" else [])]
        if at > target:
            return [_item(_DEFAULT)]
    return []


def _section_at(doc, n: int) -> str | None:
    """The section open at 1-based line n."""
    for s in reversed(doc.sections):
        if s.start < n:
            return s.name if s.end is None or n < s.end else None
    return None


def _values(key: str, fw) -> list[t.CompletionItem]:
    virtual = [f"{p}{x}" for p in ("USBD", "USBH") for x in range(1, 17)]
    channels = [_item(str(c)) for c in range(1, 17)] + [_item("NULL")]
    match key:
        case "VERSION":
            return [_item("1")]
        case "TYPE":
            return [_item(x) for x in sorted(TYPES)] + _gated(sorted(TYPES_3_20), (3, 20), fw)
        case "OUTPORT":
            return [_item(x) for x in sorted(OUTPORTS)] + _gated(virtual, (3, 0), fw)
        case "INPORT":
            return [_item(x) for x in sorted(INPORTS)] + _gated(virtual, (3, 0), fw)
        case "OUTCHAN":
            return channels
        case "INCHAN":
            return channels + [_item("ALL")]
        case "MAXRATE":
            return [_item(str(r)) for r in sorted(MAXRATES, reverse=True)] + [_item("NULL")]
    return []


def _gated(labels: list[str], floor: tuple[int, int], fw) -> list[t.CompletionItem]:
    return [_item(x, f"from {floor[0]}.{floor[1]:02}") for x in labels] if fw >= floor else []


def _item(label: str, detail: str | None = None) -> t.CompletionItem:
    return t.CompletionItem(label=label, detail=detail)
```

```python
def fix_all(text: str, uri: str, fw=LATEST) -> t.CodeAction | None:
    fixed, applied = fix(text, fw)
    if fixed == text:
        return None
    lines = text.split("\n")
    whole = t.Range(t.Position(0, 0), t.Position(len(lines) - 1, len(lines[-1])))
    return t.CodeAction(
        title=f"Hapax: fix all ({len(applied)} {'repair' if len(applied) == 1 else 'repairs'})",
        kind=t.CodeActionKind.QuickFix,
        edit=t.WorkspaceEdit(changes={uri: [t.TextEdit(whole, fixed)]}),
    )
```

```python
"""pygls wiring: settings, document events and requests, delegating to features."""

from pathlib import PurePath

from hapax import config
from hapax.rules import LATEST, parse_fw
from lsprotocol import types as t
from pygls.lsp.server import LanguageServer

from . import features


class HapaxServer(LanguageServer):
    fw = LATEST
    warn = True


server = HapaxServer("hapax-lsp", "0.1.0", text_document_sync_kind=t.TextDocumentSyncKind.Full)


def configure(ls: HapaxServer, options) -> None:
    options = options or {}
    options = options.get("hapax", options)  # didChangeConfiguration nests settings under "hapax"
    ls.warn = bool(options.get("warn", config.load().get("warn", True)))
    if "fw" in options:
        try:
            ls.fw = parse_fw(str(options["fw"]))
        except ValueError as e:
            ls.window_log_message(t.LogMessageParams(t.MessageType.Warning, f"hapax-lsp: {e}"))


def publish(ls: HapaxServer, uri: str) -> None:
    doc = ls.workspace.get_text_document(uri)
    name = PurePath(doc.path).name if doc.path else None
    ls.text_document_publish_diagnostics(t.PublishDiagnosticsParams(
        uri=uri, diagnostics=features.diagnostics(doc.source, ls.fw, name, ls.warn)))


@server.feature(t.INITIALIZE)
def initialize(ls: HapaxServer, params: t.InitializeParams):
    configure(ls, params.initialization_options)


@server.feature(t.WORKSPACE_DID_CHANGE_CONFIGURATION)
def did_change_configuration(ls: HapaxServer, params: t.DidChangeConfigurationParams):
    configure(ls, params.settings)
    for uri in ls.workspace.text_documents:
        publish(ls, uri)


@server.feature(t.TEXT_DOCUMENT_DID_OPEN)
def did_open(ls: HapaxServer, params: t.DidOpenTextDocumentParams):
    publish(ls, params.text_document.uri)


@server.feature(t.TEXT_DOCUMENT_DID_CHANGE)
def did_change(ls: HapaxServer, params: t.DidChangeTextDocumentParams):
    publish(ls, params.text_document.uri)


@server.feature(
    t.TEXT_DOCUMENT_SEMANTIC_TOKENS_FULL,
    t.SemanticTokensLegend(token_types=features.TOKEN_TYPES, token_modifiers=[]),
)
def semantic_tokens(ls: HapaxServer, params: t.SemanticTokensParams):
    return t.SemanticTokens(data=features.semantic_tokens(ls.workspace.get_text_document(params.text_document.uri).source))


@server.feature(t.TEXT_DOCUMENT_COMPLETION, t.CompletionOptions(trigger_characters=["[", "/", " "]))
def completion(ls: HapaxServer, params: t.CompletionParams):
    text = ls.workspace.get_text_document(params.text_document.uri).source
    return features.completion(text, params.position.line, params.position.character, ls.fw)


@server.feature(t.TEXT_DOCUMENT_CODE_ACTION)
def code_action(ls: HapaxServer, params: t.CodeActionParams):
    uri = params.text_document.uri
    action = features.fix_all(ls.workspace.get_text_document(uri).source, uri, ls.fw)
    return [action] if action else []


def main() -> None:
    server.start_io()
```

```lua
-- Hapax instrument definitions are .txt files; the first non-comment line decides.
local starts = {
  VERSION = true, TRACKNAME = true, TYPE = true, OUTPORT = true,
  OUTCHAN = true, INPORT = true, INCHAN = true, MAXRATE = true,
}

vim.filetype.add({
  extension = {
    txt = function(_, bufnr)
      for _, line in ipairs(vim.api.nvim_buf_get_lines(bufnr, 0, 50, false)) do
        local word = line:gsub("#.*", ""):match("^%s*(%S+)")
        if word then
          return (word:sub(1, 1) == "[" or starts[word:upper()]) and "hapax" or "text"
        end
      end
      return "text"
    end,
  },
})
```

````markdown
# hapax-lsp

A language server for Squarp Hapax instrument definitions: diagnostics, highlighting, completion and a fix-all action, in any editor with an LSP client.
Validation comes from [hapax-tui](https://github.com/claytron/hapax-tui), so the editor reports exactly what `hapax validate` reports.

## Install

```sh
uv tool install git+https://github.com/claytron/hapax-lsp
```

This puts `hapax-lsp` on your `PATH`; it speaks LSP over stdio.

## Settings

| Setting | Default | Meaning |
|---|---|---|
| `fw` | `3.21` | Target Hapax OS, `1.12` to `3.21` |
| `warn` | `warn` in `~/.config/hapax/config.toml`, else `true` | Report warnings as well as errors |

Send them as `initializationOptions`, or as `workspace/didChangeConfiguration` settings under a `hapax` key.

## Neovim (0.11+)

Add the bundled runtime directory and enable the server:

```lua
vim.opt.runtimepath:append("/path/to/hapax-lsp/editors/nvim")
vim.lsp.enable("hapax")
```

Instrument definitions are `.txt` files, so `ftdetect/hapax.lua` marks a `.txt` buffer as `hapax` when its first non-comment line is a directive (`VERSION`, `TRACKNAME`, `TYPE`, ...) or a section header.
Other `.txt` files stay `text`.
Highlighting comes from semantic tokens, linked to your colour scheme's `@lsp.type.*` groups.
Run the fix-all action with `vim.lsp.buf.code_action()`.

## Other editors

Map Hapax `.txt` files to a `hapax` language however your editor allows, for example by the directory you keep instruments in, and run `hapax-lsp` for it.

## Development

uv run pytest
```
````
